# BD Radar

A business development dashboard for technical recruitment in crypto and Web3.

BD Radar surfaces companies that are likely to need engineering talent, ranks them
by priority, and turns them into a simple daily workflow: triage new leads, work a
pipeline, set follow ups, and match opportunities against candidates.

It refreshes automatically every morning.
